# ТЗ: Lunar Landing Site Navigator

Команда infinium · 14 ноября 2026

## 1. Цель и ставка на победу

Делаем веб‑приложение, которое за 30 секунд отвечает на вопрос планировщика миссии: «Если посадка сдвинется на другую дату или в соседнюю точку, хватит ли нам Солнца и связи с Землёй?». Именно этот сценарий описан в тексте задачи как главная боль.

Рабочее название: **Lunar Site Navigator**.

Жюри оценивает по пяти критериям:

| Критерий | Чем берём |
| --- | --- |
| Impact | Сравнение сценариев «точка + дата» рядом, с понятным вердиктом по энергии и связи. |
| Creativity | Панорама неба с настоящим горизонтом из рельефа и «ползунок задержки запуска». |
| Validity | Страница проверки: наши углы Солнца и Земли сверяются с JPL Horizons, расхождение показано числом. Горизонт по рельефу LOLA. |
| Relevance | Закрываем все семь пунктов раздела Objectives, включая режим для новичков. |
| Presentation | Видео на 30 секунд: запуск задержали на две недели, инструмент сразу показывает последствия. |

Главный принцип: лучше меньше функций, но каждая работает точно и выглядит законченной. Точность расчётов важнее 3D‑эффектов.

## 2. Пользователи и сценарии

| Пользователь | Что хочет | Что получает |
| --- | --- | --- |
| Планировщик миссии | Быстро сравнить запасные точки и даты | Таблица сценариев с метриками, экспорт CSV, ссылка на сценарий |
| Преподаватель | Показать, почему южный полюс сложный | Анимация лунных суток и подсказки простым языком |
| Любопытный посетитель | Увидеть небо с поверхности Луны | Панорама с Солнцем и Землёй над горизонтом |

Ключевые сценарии:

1. **Одна точка, одна дата.** Положение Солнца и Земли относительно горизонта, время до заката и до захода Земли.
2. **Сравнение точек.** Две‑четыре точки на одну дату, метрики рядом.
3. **Сдвиг даты.** Ползунок «задержка на N дней», как меняются энергия и связь.
4. **Своя точка.** Ввод координат или клик по карте полюса.
5. **Год целиком.** Календарь на 12 месяцев, лучшие окна для посадки.

## 3. Функции

Обязательный минимум: список 10–12 точек с источниками координат; свои координаты; дата и время в UTC с воспроизведением; панорама неба 360° с рельефом; метрики с вердиктом; таймлайн на 30 дней с окнами «свет», «связь», «и то и другое»; сравнение до четырёх сценариев; страница проверки против JPL Horizons.

Метрики: высота Солнца; видимая доля диска Солнца над рельефом; время до заката и восхода; освещённость за окно миссии (14 дней); самая длинная ночь; индекс мощности (следящая и горизонтальная панель); высота Земли над рельефом; связь при запасе 2°; время до захода Земли; доступность связи и самый длинный перерыв; общее рабочее окно.

Усиление по приоритету: ползунок задержки 0–60 дней; календарь на год; режим Explain; ссылка на сценарий и CSV; 3D‑вид последним.

## 4. Данные

- JPL Horizons API: эталон для проверки точности.
- LOLA DEM (NASA PGDA и PDS): рельеф для горизонта.
- Quickmap и Moon Trek: сверка координат точек.
- astronomy-engine: расчёт Солнца, Земли и ориентации Луны в браузере.

Физика для подсказок: наклон оси Луны около 1,5°, поэтому на полюсе Солнце ходит вдоль горизонта; диск Солнца около 0,53°, Земли около 1,9°; Земля качается из‑за либрации; лунные сутки 29,5 земных суток. Числа по памяти, сверить с источниками.

## 5. Стек

Next.js + TypeScript, Tailwind, astronomy-engine, SVG/Canvas, Web Worker, серверная функция Vercel для Horizons, Python для подготовки рельефа, Vitest. Весь интерфейс на английском.

## 6. Экраны

Site (главный, без кликов), Compare, Calendar, Validation, About. Цвета: жёлтый для Солнца и энергии, синий для Земли и связи. Время в UTC. Переключатель Explain / Expert. Работает на телефоне.

## 7. Приёмка

- [ ] Расхождение с JPL Horizons не больше 0,1° для 5 точек.
- [ ] Контроль: Apollo 11, Солнце низко на востоке, около 10°.
- [ ] Маски горизонта по LOLA минимум для 8 точек юга.
- [ ] Шеклтон и Connecting Ridge освещены заметно лучше соседних низин.
- [ ] Пять сценариев работают на компьютере и телефоне.
- [ ] Первый экран быстрее 3 секунд.
- [ ] Сайт открывается в инкогнито без входа.
- [ ] Все тексты на английском, у данных указаны источники.

## 8. План

1. Основа: каркас, Vercel, расчёт и сверка с Horizons.
2. Главный экран: панорама, таймлайн, метрики, маски горизонта.
3. Сравнение, календарь, свои координаты, Explain, Validation.
4. Полировка, видео, страница сдачи. Отправить до дедлайна.

Резать по порядку: 3D, CSV, свои координаты, календарь. Не резать: панорама, метрики, сравнение, сверка с Horizons.

## 9. Сдача

Поля страницы проекта: Project Name, High-Level Summary, Demo (видео до 30 с или до 7 слайдов, на английском), Link to Final Project (Vercel + публичный GitHub), Detailed Description, Use of SI, NASA Data (минимум один ресурс NASA), Partner Data. Без лиц и голосов людей младше 18 лет.

## 10. Риски

- Файлы рельефа большие: начинать с полярных IMG LOLA.
- Расчёт расходится с Horizons: перейти на таблицы Horizons.
- Horizons недоступен: показывать сохранённые эталоны.
- 3D съедает время: резать первым.
